NETSCOPE | COMPUTER NETWORKS MINI PROJECT

Topic: Simulate Peer-to-Peer vs Client-Server Architecture
Team: Dhruv Paleja (I081), Manan Shah (I053), Armaan Lad (I076)
B2 / Group 1

1. EXTRACT the complete ZIP. Do not run files from inside the ZIP viewer.
2. Install Node.js 22 or newer if needed.
3. Windows: double-click start-windows.bat.
   macOS/Linux: open Terminal here and run sh start-mac-linux.sh.
   Any platform: open Terminal here and run npm start.
4. Open http://127.0.0.1:3000 in your browser.
5. Keep the terminal open. Ctrl+C stops the application.

No npm install, API key, account or database is required.
Do not open public/index.html directly; it needs the local Node/TCP engine.
